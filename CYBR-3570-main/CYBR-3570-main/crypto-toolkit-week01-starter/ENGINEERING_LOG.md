### Security Lesson
Classical ciphers are useful for learning, but they should never be used to protect real data.

### Reflection
- The Caesar Cypher is undersatndble but also easily breakable. The brute force attacks knows it out the park in a second. If I ever need an encryption method in a project always use methods that are widley used in the industry. Trying to make your own encryption is a one way ticked to getting exploited.
